AGGR <- function(x, cutoff=4) {
  VIM::aggr(x,combined=T,border=NA,plot=F) -> miss
  print("Distribution of missing")
  print(table(miss$count))
  kp <- which(miss$count>cutoff)
  miss$combinations <- miss$combinations[kp]
  miss$percent      <- miss$percent[kp]
  miss$count        <- miss$count[kp]
  miss$tabcomb      <- miss$tabcomb[kp,]
  plot(miss, combined=T, border=NA, cex.axis=0.75 )
}

# Missing data by Variable

The table below presents the number of missing values by variable. There are two types of missing. THe first is structural missing, as many questions were only presented on 1-2 of three forms and teachers. Structural missing is where teachers were not presented with questions due to the nature of the survey forms. The second is not answered missing, which occurs when teachers were presented with items, but chose not to answer them.

```{r Makegraphs}
MakeGraphs <- function(var,lbl="Student harassment in school") {
  BTGINTT4$TheVar <- BTGINTT4[[var]]
  
  hist.rug(BTGINTT4$TheVar,describe = F,main = lbl)
  
  ord <- BTGINTT4 %>%
    group_by(CNTRY) %>% 
    mutate(m=mean(TheVar,na.rm=T)) %>% 
    ungroup %>% 
    with(unique(CNTRY[order(m)]))
  
  customggridges <- function(df) {
    ggplot(df,aes(x=TheVar ,y=CNTRY,fill=IsNordic,color=IsNordic)) +
      labs(y="Country", x=lbl) +
      geom_density_ridges()+theme_bw()+
      see::scale_color_okabeito(palette="black_first",order=c(9,9))+
      see::scale_fill_okabeito(palette="black_first",order=c(1,3))+
      theme(axis.title.y=element_text(size=10),
            axis.text.y = element_text(color= ifelse(unique(df$CNTRY) %in% c("DNK","NOR","SWE","FIN","ISL"),"black","grey60"), 
                                       face = ifelse(unique(df$CNTRY) %in% c("DNK","NOR","SWE","FIN","ISL"),"bold","plain"), 
                                       size = 10) )+
      labs(color="Country\ngroup",fill="Country\ngroup",x=lbl)
  }
  print(
    BTGINTT4 %>% filter(!is.na(TheVar)) %>% 
             mutate(IsNordic=ifelse(CNTRY %in% c("DNK","NOR","SWE","FIN","ISL"),"Nordic","Other") %>% factor) %>% 
             group_by(CNTRY,IsNordic) %>% 
             mutate(m=mean(TheVar,na.rm=T)) %>% 
             ungroup %>% 
             mutate(CNTRY=factor(CNTRY,unique(CNTRY[order(m)])) ) %>% 
             arrange(CNTRY) %>% 
      customggridges
      
  )
  
  customboxplot <- function(df) {
    
    ggplot(df,aes(y=m ,x=CNTRY,color=IsNordic,shape=IsNordic) ) +
      geom_pointrange(aes(ymin=q25,ymax=q75),linewidth=3) +
      geom_pointrange(aes(ymin=q05,ymax=q95),linewidth=1) +
      geom_point(color="black") +
      coord_flip() +
      labs(y=lbl,x="") + theme_bw()+
      see::scale_color_okabeito(palette="black_first",order=c(2,6))+
      theme(axis.title.y=element_text(size=10),
            axis.text.y = element_text(color= ifelse(unique(df$CNTRY) %in% c("DNK","NOR","SWE","FIN","ISL"),"black","grey60"), 
                                       face = ifelse(unique(df$CNTRY) %in% c("DNK","NOR","SWE","FIN","ISL"),"bold","plain"), 
                                       size = 10) )
  }
  print(
    BTGINTT4 %>% filter(!is.na(TheVar)) %>% 
      mutate(IsNordic=ifelse(CNTRY %in% c("DNK","NOR","SWE","FIN","ISL"),"Nordic","Other") %>% factor) %>% 
      group_by(CNTRY,IsNordic) %>% 
      summarize(m  =mean(    TheVar,na.rm=T),
                q05=quantile(TheVar,0.05,na.rm=T),
                q25=quantile(TheVar,0.25,na.rm=T),
                q75=quantile(TheVar,0.75,na.rm=T),
                q95=quantile(TheVar,0.95,na.rm=T),
                .groups="drop") %>%
      mutate(CNTRY=factor(CNTRY,ord) ) %>% 
      arrange(CNTRY) %>% 
      customboxplot
  )
}
```

In the following sections are there four graphs. The first shows just the overall distribution of the main variable of focus. The second shows country specific distributions. The third breaks down the distribution for the nordic countries versus non-nordic countries into twenty discrete points, where each point represents 5 % of the population. This gives a simpler approach for showning the distribution. The last figure has a black dot for means, wider lines that go from the 25th percentile to the 75th percentile and thinner lines that go from the 5th percentile to the 95th percentile.

# Interactions

Each possible interaction has up to six graphs

- the first shows the average value of the variable on the y-axis based on values of the x-axis. Here the difference between the two lines shows the difference between nordic and non-nordic countries. The interaction can be seen by variation in the distance between lines across values of the x-axis
- the second graph simply adds in markers that explicitly show the distance between lines to emphasize this feature.
- the third graph shows the same thing as the last graph for individual variables (i.e., the 5th, 25th, mean, 75th, and 95th percentiles) for both the nordics and the non-nordics. Here, there are lines connecting the mean, 25th percentile, and 75th percentile to show differences and and the same figures are provided for both below and over the mean for the second variable. Looking across panes of the graph to see differences in the slope of the line shows interactions... We could reduce this to just look at means and/or to have more panes if that is desirable.
